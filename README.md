AI Coordinator Bot
AI Coordinator Bot — это Telegram-бот на базе Python и aiogram 3.x, разработанный для автоматизации процессов координации команды, сбора ежедневной отчетности и управления рабочими планерками.
Основные возможности

1. Управление пользователями и доступ
Разделение ролей на Сотрудников и Администратора (Руководителя).
Автоматическая регистрация пользователей при первом старте.

3. Ежедневные планы и отчеты
Сбор ключевых задач сотрудников на день.
Сбор итогов выполненной работы за день.
Автоматическое формирование единой сводки по всем сотрудникам для администратора.

5. Планерки и уведомления
Создание планерок администратором с указанием темы, даты и времени.
Автоматическая рассылка информации о новой встрече всем участникам.
Управление и перенос встреч через команду /reschedule с выбором из списка и авто-оповещением сотрудников.
Автоматическая отправка напоминания сотрудникам за 20 минут до начала любой планерки.

Технологический стек
Язык программирования: Python 3.12
Фреймворк бота: aiogram 3.x
База данных: SQLite (aiosqlite)
Планировщик задач: APScheduler
Управление состоянием: FSM (Finite State Machine)

Структура проекта
ai_coordinator_bot/

├── .env                 # Переменные окружения (токен, ID админа)

└── README.md            # Документация проекта

Запуск проекта
1. Клонирование репозитория
Bash
git clone https://github.com/your-username/ai_coordinator_bot.git
cd ai_coordinator_bot

3. Настройка виртуального окружения
Bash
python3 -m venv .venv
source .venv/bin/activate  # Для Linux / macOS
# .venv\Scripts\activate   # Для Windows

3. Установка зависимостей
Bash
pip install aiogram aiosqlite apscheduler python-dotenv

5. Настройка конфигурации (.env)
Создайте файл .env в корневой директории проекта и укажите ваши данные:
Фрагмент кода
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_ID=123456789

7. Запуск бота
Bash
python main.py

В разработке
Распознавание голосовых сообщений (OpenAI Whisper API) для отправки планов и отчетов.
Автоматическая рассылка запросов планов и отчетов по установленному времени.
ИИ-анализ выполненных задач и отчетов на базе OpenAI GPT.
